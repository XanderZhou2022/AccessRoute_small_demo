## 九龍塘重點路線

又一城地下官方通道 → 官方電梯 → 低層通道 → 達之路／九龍塘站天橋 → 車站側天橋接駁點。共約 281.3 m，包含室內、垂直轉換和約 80.4 m 天橋。起終點均為官方路網節點，沒有為了串接而畫人工直線。

小範圍原始網絡共 4,372 條記錄；又一城名稱相關記錄 163 條。已保留可用連通分量與電梯備選，未把 XY 相交的不同高度道路錯接。樓層視圖顯示官方通道中心線：資料包含 G、UG、LG1、LG2、MTR level 等通道，**不包含商舖邊界或完整單元平面**。車站接駁點為官方天橋路段 200007733 的端點，不延伸至付費月台。

## 主題覆蓋與缺口

石硤尾邨服務設施大樓同時承載長者中心、護養院及社會服務。社署目錄支持一樓長者服務、二至三樓護養院用途；本次 Demo 終點是公共走廊，不宣稱已定位到服務櫃枱或院舍內部。原始全樓層資料保留供後續擴展。

- [社署深水埗服務目錄](https://www.swd.gov.hk/tc/pubsvc/district/ssp/infobook/)
- [社署長者資訊：石硤尾護養院地址](https://elderlyinfo.swd.gov.hk/tc/search-result-ccsv?items_per_page=30&page=11&sort_by=field_bi_name_en_value)

醫院類別尚未滿足完整室內覆蓋。廣華醫院的醫管局官方位置和周邊 2,240 條步行路網已下載，保留為候補；沒有把醫院位置點或附近街道冒充醫院室內圖。西營盤社區綜合大樓及白田社區綜合大樓也保留候補資料，因本次約束下未找到可信度足夠的室外接駁而未註冊。長者居住比例尚未接入人口統計，選址依據是長者服務與社區用途，未作人口密度排名。

現用室內 WFS 目錄為 689 個建築／場地；完整 CSDI 索引 787 筆包含 98 個港鐵站。兩套索引均已保存。又一城不存在於單元平面索引，但存在於另一套官方三維行人路網。

## 可供下游使用的資料

主場景合計 6,609 條設施／商戶 POI 記錄（含未命名記錄），以及 17,852 條分區路網記錄（鄰近區域可能重疊，不能視作全港唯一記錄數）。

| 入口 | 用途 |
|---|---|
| `data/location-catalog.json` | 12 地點總目錄、主題、完整度、原始路徑及明確缺口 |
| `data/scene-build-configs.json` | 11 個平面圖場景的穩定 venue、floor、station ID |
| `data/scenes/index.json` | 前後端共用的正式 12 場景註冊表 |
| `data/raw/<venue-id>/` | 全樓層 levels / units / openings / amenities / occupants 原文，並非只保留 Demo 兩層 |
| `data/pedestrian/<venue-id>/network.geojson` | 完整小範圍官方三維步行網，保留高程、天橋、坡度、遮蔽、方向、障礙及開放時間引用 |
| `data/poi/<scene-id>.json` | 原始中英文名称、樓層、幾何、來源與明確 node 映射狀態 |
| `data/scenes/<scene-id>/` | 可直接離線載入的規範化路網與展示圖層 |
| `data/source-index.json` | 每份原始檔的請求 URL、時間及 SHA-256 |
| `docs/qa/location-expansion.json` | 72 次本地路由檢查與 132 配對矩陣 |

Agent 2 可以使用官方設施 ID／edge ID；Agent 3 應使用 POI 名稱作候選檢索，再核實與門口及路網節點的關係。`graphNodeId=null` 表示未匹配，不能直接取最近節點冒充定位。這些資料沒有自動寫入 `data/landmarks/`，也沒有偽造店面照片、顏色或視覺描述。又一城商戶 POI 缺失已明確標記。

## 幾何與可通行性的區別

11 個平面圖場景的室內圖仍由公共走廊等幾何推導；跨層電梯配對仍屬演示補充。新增 9 個建築場景已用官方步行路網替換原先整段直線接駁，建築端吸附上限 30 m、站口端 20 m；逐場景保存實際距離。這些短連接未經實地核實，不能等同可穿牆／跨圍欄的通行證明。沙田、大埔的接駁還使用官方室內通道中心線，會單獨顯示。

保留所有邊的 `wheelchair=unknown`；官方路網中的已知障礙、樓梯、扶梯與大於 1:12 的已知坡度被排除，`WheelchairBarrier=false` 不直接升格為無障礙已認證。`AccessTimeID` 已保存，但本期未執行開放時段規則。正式實地使用前仍需補驗。原有希慎廣場與 PopCorn 2 的演示路線保持既有行為，新下載完整路網另行保留供後續升級。

## 重建與驗收

```bash
.venv/bin/python scripts/build_scene_catalog.py
.venv/bin/python scripts/build_location_catalog.py
python3 scripts/audit_data.py
node --import tsx scripts/audit_locations.ts
npm run check
```

全部重建使用已凍結資料，不需要再次下載。採集命令 `expand_locations.py`、`download_pedestrian.py` 為低頻順序請求；後者按 OBJECTID 分頁，對照官方 count/IDs，恢復分頁遺漏，保留原始回應。`data/raw/expansion-20261004/kowloon-tong-pedestrian.geojson` 是早期截斷診斷樣本，正式完整資料入口為 `data/pedestrian/kowloon-tong-festival-walk/network.geojson`。

2026-10-04：55 項測試及 TypeScript／Vite 生產構建通過。新增測試檢查 12 場景 × 3 畫像 × 2 方向、嚴格模式、132 配對，以及九龍塘室內／電梯／天橋分段與關梯後的改路結果。公開 GitHub Pages 尚未由本次操作更新。

## 周邊建築底圖修正

12 個場景的周邊輪廓改用地政總署 [Building 資料集](https://portal.csdi.gov.hk/csdi-webpage/dataset/landsd_rcd_1637211194312_35158)，取路網範圍外擴 350 m，按官方 OBJECTID 清單分批下載並核對完整性。原先的室內 venue 目錄只包含有室內圖的場地，不能代表完整周邊建築。原始回應保存在 `data/raw/buildings/`，每場景統計見 `docs/qa/surroundings.json`。

首次更新使用 `.venv/bin/python scripts/build_surroundings.py --download`；離線重建使用 `.venv/bin/python scripts/build_surroundings.py`，並已接入完整場景重建流程。建築輪廓為官方幾何，高度仍為縮放／封頂示意；無高度記錄使用預設值。周邊建築只作展示，不增加可通行路段。
