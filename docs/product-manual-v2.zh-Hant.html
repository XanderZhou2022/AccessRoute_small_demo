01・版本變更

相對於舊手冊的變更

本比較以你提供的《AccessRoute HK Product Manual》PDF 及目前程式庫內的產品手冊差異審核為依據。「已變更」代表目前專案有相應改動或補充說明，不代表舊手冊提及的每項功能都是全新功能，也不代表已完成實地測試。

範疇目前版本的變更／補充狀態
首頁流程一般入口現時採用地圖卡片流程：選地點、設定出行需要、比較路線，再導航或尋求協助。舊版完整規劃工作台仍可透過 /?legacy=1 開啟。已更改
出行設定現行流程提供五種畫像：步行、輪椅、長者、嬰兒車及重行李；照顧者亦可設定電梯、樓梯／扶手電梯、坡度、步速及路線目標等。已擴充
天氣天氣功能可使用香港天文台開放數據，並標示資料是即時或上次快取的過期資料；全港天氣並非精確的所在地預報。已更新
無障礙證據更清楚說明來源資料中仍有不少未知的通行屬性。「僅使用已核實通道」可排除未知路段，但計算結果不等於無障礙認證。已釐清
介面易用性專案已加入略過導覽連結、鍵盤焦點提示、較大的觸控目標、減少動態效果及相關頁面的高對比支援。已改善
AI 協助文字出行偏好、相片路障回報、相片位置協助及語音指引分為不同流程。介面或模擬測試不能證明真實服務已啟用，亦不能證明實地辨識準確度。已釐清
端到端功能舊手冊中的指定 13 步旅程及其準確度目標尚未獨立重現。即時室內定位、即時港鐵無障礙資料，以及完整手機／操作員整合仍未完成或只部分支援。重要限制
出發前請留意：本產品仍是研究演示。路線幾何、入口、斜度、電梯及公眾通行權均須另行核實。

目前版本仍有 12 個可選場景、地圖檢視、路線計算及模擬電梯事件。舊手冊已提及相近能力，因此不會把它們列為全新功能。

04・開始使用

啟動演示

首次設定

  1. 在 Windows 或 macOS 電腦安裝 Node.js 22 LTS 或更新版本。
  2. 解壓縮專案資料夾，並在該資料夾開啟終端機。
  3. 安裝依賴並啟動本機演示：
npm ci
npm run dev
  1. 使用新版瀏覽器開啟 http://127.0.0.1:5173/map-demo/index.html。使用期間請勿關閉終端機。

之後再次使用，只需執行 npm run dev 並開啟網址。要停止服務，請在終端機按 Ctrl+C。

選用：啟用 Qwen 智能協助

沒有 AI 金鑰仍可規劃路線。要啟用 Qwen 流程，將 .env.example 複製為 .env，在該本機檔案填入私密的 DASHSCOPE_API_KEY，然後重新啟動演示。切勿把金鑰輸入瀏覽器或放進截圖。

DASHSCOPE_API_KEY=your_private_key
本機正式構建：執行 npm run build，再執行 npm start，並開啟 http://127.0.0.1:8787/map-demo/index.html。
05・規劃路線

選擇地點與出行需要

  1. 按地圖頂部的地點選擇器，選擇出發地和目的地，再套用選擇。
  2. 展開底部卡片，選擇出行畫像：步行、輪椅、長者、嬰兒車或重行李；按需要調整可用的路線偏好。
  3. 按畫面底部的搜尋路線。
  4. 比較有蓋及較短路線、檢視其限制，再按開始導航。

切換地圖檢視

使用概覽地圖查看周邊路線，使用樓層導航查看室內樓層幾何。可切換樓層並使用地圖縮放控制。請按畫面檢查路段；除非已另行核實，所有路線均只屬演示。

未知不等於無障礙：來源資料可呈現幾何，但不一定確認門寬、斜度、開放時間、通行權或電梯服務。即使選擇「僅使用已核實通道」，剩餘路線亦不等於已獲認證。
06・導航與求助

查看指引及模擬設施停用

  1. 在路線預覽開始導航演示。
  2. 閱讀目前指引，並查看對應的地圖路段或樓層。
  3. 確認周遭情況後，再按畫面控制推進步驟。進度由使用者操作，並非即時室內定位。
  4. 在電梯事件演示中模擬電梯停用，查看剩餘路線重新計算。完成後可恢復電梯或重設行程。

選用 AI 協助

按？求助按鈕使用設施或位置協助；出行偏好可在規劃卡片內輸入。視乎流程而定，Qwen 需要已設定後端；套用前請先檢查建議的匹配結果或路線變更：

  • 出行偏好：以文字描述需要，檢視系統建議後才套用。
  • 相片回報路障：提交相片，先檢查設施／候選結果，再套用事件或重新規劃。
  • 相片找位置：檢視比對到的地點候選，確認後才更改路線起點。
  • 語音指引：要求播報下一段指引；語音輸出取決於裝置是否安裝所需語音。
07・易用性、天氣與限制

易用性功能

  • 使用略過導覽連結及鍵盤焦點提示，直接前往主要內容。
  • 可使用瀏覽器／裝置的文字放大、高對比及減少動態效果設定；部分演示畫面另有大字或較大觸控目標模式。
  • 如需語音播報，請在作業系統安裝香港粵語語音（如有）。實際語音辨識及播報效果視乎裝置和瀏覽器。

天氣資料

後端運作且天氣服務有資料時，程式可顯示香港天文台觀測、預報及警告。請留意即時／過期狀態和更新時間。全港讀數未必反映你所在街道或建築物的實際情況。

目前限制

定位與導航
  • 沒有持續即時室內定位。
  • 導航步驟由使用者手動推進。
  • 地圖範圍限於演示場景。
無障礙與交通
  • 不少通行屬性仍未知，須實地核實。
  • 電梯狀態為模擬資料，並非即時資訊。
  • 已保存的港鐵接駁並非即時班次、票價或無障礙資料。
AI 與相片
  • AI 需要已設定的後端金鑰及網絡。
  • 尚未認證實地辨識及外部服務行為。
  • 請檢查並確認系統提出的候選結果。
帳戶與服務
  • 設定可能只儲存在本機瀏覽器。
  • 工作階段／操作員功能只供本機演示，並非正式服務。
  • 介面檢查不等於 WCAG 認證。
安全提示：AccessRoute HK 是研究演示，並非經認證的實地無障礙導航服務。出行前請確認路線狀況、公眾通行權、車站設施、電梯服務及安全資訊。如有疑問，請選擇已核實的替代路線或向場地／營運者求助。
